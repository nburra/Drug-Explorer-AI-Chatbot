# Drug-Explorer-AI-Chatbot
The Drug Explorer AI Chatbot is an interactive AI-powered web application that implements a Retrieval-Augmented Generation (RAG) workflow to answer questions, provide expanded explanations, and display metrics about specific drugs stored in a database. The application retrieves relevant drug information and uses an LLM to generate accurate, context-based responses. This application is built using Streamlit for a dynamic UI and relies on MySQL for storage of structured data. The application is containerized using Docker for consistent deployment, and uses Groq API to connect to the llama-3.1-8b-instant LLM.
